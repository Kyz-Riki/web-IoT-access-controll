Konfigurasi Jadwal Akses

Atur kapan setiap level akses diizinkan masuk. Admin selalu 24/7.

Cara kerja jadwal akses:

  • admin → Akses 24/7, tidak memerlukan jadwal dan tidak dibatasi.
  • Level Kustom (contoh: Karyawan, OB, Shift Malam) → Bisa diatur jadwalnya.
  • Jika tidak ada jadwal sama sekali untuk suatu level, maka level tersebut diizinkan akses kapan saja.
  • Satu level bisa punya banyak jadwal (misal: Senin-Jumat pagi + Sabtu siang).

Belum ada jadwal

Ketik nama level baru atau pilih yang sudah ada. Admin otomatis 24/7.
